# מסיר אוצריא טוטאלי

כלי הסרה מלאה של [אוצריא](https://github.com/Sivan22/otzaria) — מאתר ומוחק כל שארית
שהתוכנה השאירה במחשב, לרוחב **כל גרסאותיה מאז ומעולם**: תיקיות התקנה, שורשי נתונים
בשמות שהשתנו לאורך הדורות, הספרייה והאינדקס, גיבויים, רכיבים נלווים, רישומי Windows,
קיצורים, רכיבי `PATH`, כללי חומת אש, משימות מתוזמנות ועקבות מערכת.

הכלי אינו נוגע בשום רכיב שהמחשב זקוק לו לתפעולו, ואינו מוחק קבצים שהמשתמש יצר בעצמו
אלא בבקשה מפורשת.

> **כלל הבעלות:** שם שמכיל "otzaria" אינו מספיק — גם לא שם היעד עצמו. כל תיקייה
> שנמחקת חייבת להוכיח בעלות: `otzaria.exe` עם חבילת ה-assets שלצידו, `seforim.db`
> בתיקיית ספרים, קובץ `.hive` בשורש נתונים, וכן הלאה. ריפו קוד המקור `C:\otzaria` —
> ש-Windows רואה כזהה לנתיב ההתקנה ההיסטורי `C:\Otzaria` — נפסל גם כשמונח בו
> build artifact בשם `otzaria.exe`, וזו בדיקה אוטומטית.
> הפירוט המלא ב-[docs/INVENTORY.md](docs/INVENTORY.md#כלל-הבעלות).

## התקנה

הורידו את קובץ ה-ZIP מהרילייס האחרון, חלצו אותו, ופתחו PowerShell בתיקייה שנוצרה.
אין מה להתקין — הכלי הוא סקריפטים בלבד, בלי תלויות.

## Windows

```powershell
powershell -ExecutionPolicy Bypass -File .\Uninstall-Otzaria.ps1
```

זו **סריקה בלבד** — הכלי מדפיס מה יימחק, מחשב נפחים, ושומר דוח JSON. שום דבר לא נמחק.

להסרה בפועל:

```powershell
powershell -ExecutionPolicy Bypass -File .\Uninstall-Otzaria.ps1 -Remove
```

הסקריפט יבקש הרשאות מנהל בעצמו (נדרשות ל-`Program Files`, `ProgramData` ו-`HKLM`).

### אפשרויות

| דגל | משמעות |
|---|---|
| `-Remove` | מוחק בפועל. בלעדיו — סריקה ודיווח בלבד |
| `-Yes` | בלי שאלת אישור |
| `-KeepLibrary` | משאיר את הספרייה (הספרים והאינדקס) — בדרך כלל עשרות ג'יגה |
| `-KeepBackups` | משאיר את תיקיות הגיבוי |
| `-KeepData` | משאיר את נתוני המשתמש (הגדרות, סימניות, הערות, תוספים) |
| `-IncludeUserFiles` | מוחק גם קבצים שהמשתמש שמר בעצמו (`.otzplugin`, גיבויי JSON, מתקינים שהורדו) |
| `-Deep` | סריקות איטיות: התקנות ניידות בכל הכוננים, רשימות קפיצה, דוחות WER |
| `-SkipVendorUninstaller` | לא מריץ את מסיר ההתקנה הרשמי לפני המחיקה הידנית |
| `-NoElevate` | לא מנסה להפעיל מחדש כמנהל |
| `-ReportPath` | נתיב לדוח ה-JSON |

דוגמה — להסיר את התוכנה ולהשאיר את הספרים:

```powershell
.\Uninstall-Otzaria.ps1 -Remove -KeepLibrary -KeepBackups
```

## Linux ו-macOS

```bash
./uninstall-otzaria.sh
```

```bash
./uninstall-otzaria.sh --remove
```

הדגלים: `--remove`, `--yes`, `--keep-library`, `--keep-backups`, `--keep-data`.
הסקריפט תואם Bash 3.2 — ברירת המחדל ב-macOS.
מחיקת יעדים מערכתיים (`/opt`, `/usr`, `/var/lib`, `/Applications`) דורשת `sudo`.

## סדר הפעולות

1. **תהליכים** — סוגר את `otzaria.exe`, את חנות התוספים ואת תהליכי ה-WebView2 שלהם.
2. **מסיר ההתקנה הרשמי** — מריץ בשקט כל רשומת הסרה של אוצריא, בשני מבטי הרישום
   ובשתי הכוורות. הרשומה חייבת להוכיח בעלות לפני ההרצה, שהיא בלתי הפיכה.
3. **סריקה** — מרחיב את המלאי הקבוע ומריץ את הסורקים הדינמיים.
4. **דיווח** — פירוט לפי קבוצות עם נפחים.
5. **מחיקה** — קובץ נעול נדחה למחיקה בהפעלה הבאה (`MoveFileEx`) במקום להישאר מאחור.

## מה נמחק, לפי קבוצות

| קבוצה | תוכן |
|---|---|
| `app` | תיקיות התקנה, קיצורים, שיוכי `otzaria://` ו-`.otzplugin`, רשומות הסרה, רכיבי `PATH` |
| `data` | שורשי הנתונים על שמותיהם ההיסטוריים — הגדרות, סימניות, טאבים, הערות, תוספים, `webview2` |
| `library` | הספרים, האינדקס ומסדי הנתונים — גם כשהועברו לנתיב מותאם |
| `backups` | תיקיות הגיבוי |
| `related` | חנות התוספים ו-`OtzariaDesktop` |
| `traces` | קבצים זמניים, דוחות קריסה, `Prefetch`, `MuiCache`, רשימות קפיצה, כללי חומת אש, משימות מתוזמנות |
| `userfiles` | קבצי `.otzplugin` וגיבויי JSON ששמורים אצל המשתמש — **מדווח בלבד** אלא אם ניתן `-IncludeUserFiles` |

הרשימה המלאה, עם המקור בקוד לכל רשומה, נמצאת ב-[docs/INVENTORY.md](docs/INVENTORY.md).

## בדיקות

```powershell
powershell -ExecutionPolicy Bypass -File .\tests\Test-Ownership.ps1
```

```bash
bash tests/test-ownership.sh
```

הבדיקות בונות מבני תיקיות זמניים ומוודאות שכל מבחן בעלות מכריע נכון — כולל רגרסיות
שנתפסו בפועל: ריפו קוד המקור נפסל, תוכנת Inno אחרת אינה נחשבת אוצריא, תת-תיקיות
גנריות ריקות (`books`, `index`, `databases`, `dictionaries`) אינן הופכות שורש לשל
אוצריא, מוצר אחר ששמו מתחיל ב-"Otzaria" אינו גורם להרצת מסיר ההתקנה שלו, ותיקייה
זמנית של כלי אחר ששמה מתחיל ב-"otzaria" אינה נמחקת. בדיקה נוספת מוודאת שלכל
מטרה במלאי מוצהר מבחן בעלות — כך שיעד חדש לא ייכנס בלי אחד.

`.github/workflows/ci.yml` מריץ אותן על Windows, Linux ו-macOS בכל דחיפה, יחד עם
בדיקת תחביר, `shellcheck`, וסריקה יבשה על רץ נקי שנכשלת אם נמצא ולו יעד קבצים אחד
במחשב שאין בו אוצריא.

## שחרור גרסה

`.github/workflows/release.yml` אורז ומפרסם רילייס. הבדיקות רצות קודם — רילייס לא
יוצא בלי שכולן עברו בשלוש הפלטפורמות.

שתי דרכים לשחרר:

```bash
git tag v1.0.0 && git push origin v1.0.0
```

או הפעלה ידנית של ‎Actions → פרסום רילייס‎ עם מספר גרסה; התג נוצר ונדחף אוטומטית.

הרילייס כולל את `otzaria-total-uninstaller-<גרסה>.zip`, קובץ `SHA256SUMS.txt` לאימות
ההורדה, ורשימת השינויים מאז התג הקודם.

## אזהרה

הכלי מוחק לצמיתות. הרץ תחילה בלי `-Remove`, קרא את הרשימה, ורק אז הסר.
מי שרוצה לשמר את הספרים או את ההערות — `-KeepLibrary` / `-KeepData` לפני `-Remove`.
